# Q056 — Spike H and ship macOS/Linux standalone plus npm packaging/update path

## Outcome

A spike selects a packaging strategy and ships verified macOS/Linux standalone artifacts plus an unpublished-but-testable npm installation/update path.

## Specification anchors

- §28 Installation and distribution
- §23.3 Managed dependency
- §27 Security and privacy

## Dependency

Requires Q055 to be merged and independently confirmed on remote `main`.

## Tier

`T0-evidence`

## Constraints

- Node.js is not required for standalone users.
- Do not publish npm or add an OSS license in this issue.
- Preserve Product Specification v0.2 commitments and acceptance criteria.
- Keep Windmill, predecessor automation tooling, and TAKT out of Heniek runtime dependencies.
- Use strict ESM TypeScript, provider-neutral public contracts, and repository conventions.

- No Windows build.
- No silent update or unsigned artifact activation.

- No unrelated backlog work or speculative scope reduction.

- [ ] ADR compares candidate packagers against native SQLite, daemon, MCP, TUI, and web asset requirements.

- [ ] Public contracts and generated schemas remain compatible or are versioned deliberately.
- [ ] `pnpm check` passes from a clean checkout on Node.js 24.
- [ ] The pull request is non-draft, self-contained, and uses `Closes <this issue>`.
