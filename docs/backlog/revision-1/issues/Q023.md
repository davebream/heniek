# Q023 — Spike G and implement the native Claude bridge

## Outcome

A session-bound bridge lets the Claude plugin dispatch native Agent-tool work and submit validated results to the daemon while explicitly handling parent absence.

## Specification anchors

- §6 System architecture
- §9.5 Native and external Claude modes
- §18.3 Native stage boundary

## Dependency

Requires Q022 to be merged and independently confirmed on remote `main`.

## Tier

`T0-evidence`

## Constraints

- The daemon never pretends it can invoke the Agent tool independently.
- Native results pass the same stage contract as external execution.
- Preserve Product Specification v0.2 commitments and acceptance criteria.
- Keep Windmill, predecessor automation tooling, and TAKT out of Heniek runtime dependencies.
- Use strict ESM TypeScript, provider-neutral public contracts, and repository conventions.

## Exclusions

- No hidden dependence on one parent transcript.
- No automatic conversion of a native stage to external execution without configured fallback.
- No factory runtime state, credentials, transcripts, or control artifacts in this repository.
- No unrelated backlog work or speculative scope reduction.

## Acceptance criteria

- [ ] ADR proves dispatch, question mediation, result submission, disconnect, reconnect, and cancellation semantics.
- [ ] Absent parent transitions the stage to WAITING_FOR_PARENT_SESSION.
- [ ] Rebinding cannot submit a result to the wrong run/stage/attempt.
- [ ] Public contracts and generated schemas remain compatible or are versioned deliberately.
- [ ] `pnpm check` passes from a clean checkout on Node.js 24.
- [ ] The pull request is non-draft, self-contained, and uses `Closes <this issue>`.

## Required tests

- Bridge token, replay, reconnect, and stale-attempt tests.
- Plugin-to-daemon native-stage integration canary.
- Regression tests for every defect discovered while implementing this issue.

## Required evidence

- Native bridge ADR and sequence trace.
- Conformance result against stage lifecycle.
- Exact commands and results for local checks.
- GitHub required-check and merge confirmation.

## Autonomous stop conditions

Stop with a typed blocker and evidence if the predecessor is not merged, queue
markers disagree, a product commitment would need to be narrowed, a required
subscription route cannot be proven, credentials could be exposed, or a genuine
technical ambiguity remains after the issue's bounded spike/ADR path.
