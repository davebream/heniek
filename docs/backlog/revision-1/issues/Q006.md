# Q006 — Implement SQLite migrations, canonical projections and append-only event journal

## Outcome

Built-in Node SQLite stores versioned migrations, transactional current projections, and an append-only event journal from which audited state can be reconstructed.

## Specification anchors

- §16.1 One canonical state per run
- §16.2 Hybrid mutability
- §16.3 Storage

## Dependency

Requires Q005 to be merged and independently confirmed on remote `main`.

## Tier

`T1-foundation`

## Constraints

- Migrations are append-only and forward-tested.
- Event ordering and projection updates share one transaction.
- Preserve Product Specification v0.2 commitments and acceptance criteria.
- Keep Windmill, predecessor automation tooling, and TAKT out of Heniek runtime dependencies.
- Use strict ESM TypeScript, provider-neutral public contracts, and repository conventions.

## Exclusions

- No provider transcript storage policy beyond references.
- No distributed database or remote coordination.
- No factory runtime state, credentials, transcripts, or control artifacts in this repository.
- No unrelated backlog work or speculative scope reduction.

## Acceptance criteria

- [ ] Fresh, upgraded, interrupted, and rolled-forward databases produce the same canonical schema.
- [ ] Every mutable projection change has an immutable causative event and correlation IDs.
- [ ] Rebuild tooling detects divergence between journal replay and stored projections.
- [ ] Public contracts and generated schemas remain compatible or are versioned deliberately.
- [ ] `pnpm check` passes from a clean checkout on Node.js 24.
- [ ] The pull request is non-draft, self-contained, and uses `Closes <this issue>`.

## Required tests

- Migration fixture matrix across every schema version.
- Crash-at-transaction-boundary and journal replay property tests.
- Regression tests for every defect discovered while implementing this issue.

## Required evidence

- Schema and migration manifest.
- Deterministic replay report.
- Exact commands and results for local checks.
- GitHub required-check and merge confirmation.
