# Security policy

Heniek is an unsupported public alpha built from source. There is no supported
release, package, binary, cloud service, security-response SLA, or production
deployment guidance yet.

## Reporting a vulnerability

Use GitHub's private
[Report a vulnerability](https://github.com/davebream/heniek/security/advisories/new)
form. Do not open a public issue for a suspected vulnerability.

Include, when safe and relevant:

- the affected commit and environment;
- the security impact and the boundary that was crossed;
- minimal reproduction steps using synthetic data;
- a proposed mitigation, if you have one.

Never send live credentials, access tokens, private keys, private repository
contents, or an unredacted doctor report. Replace sensitive values with clear
markers and attach only the smallest redacted excerpt needed to understand the
problem. If even a redacted reproduction would expose someone else's data,
describe the issue without attaching that data.

Reports are reviewed on a best-effort basis. The maintainer will coordinate
validation and disclosure through the private advisory before public details
are published.
